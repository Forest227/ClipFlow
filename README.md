# ClipFlow

> 面向 macOS 的原生剪贴板效率工具，帮助你在当前上下文附近快速找回并再次粘贴内容，同时把隐私保护放进主流程。

- **更快找回**：复制过的文本、链接、代码片段和图片，不用回忆放在哪里，呼出面板就能快速识别。
- **更少打断**：默认通过 `Option + V` 在鼠标附近呼出快捷面板，也支持自定义快捷键。
- **更安心处理敏感内容**：敏感内容遮罩、排除应用和暂停监听都在日常使用链路里，而不是藏在深层设置中。

[前往 GitHub Releases 下载](https://github.com/Forest227/ClipFlow/releases)

## 为什么值得用

ClipFlow 不是传统“囤历史”的剪贴板仓库。它围绕“找回并再次使用”设计，让你在当前任务附近完成选择、确认和回贴，而不是离开上下文去翻一长串历史记录。

## 适合谁

- 开发者：频繁处理命令、代码片段、调试输出和链接
- 设计师与内容创作者：需要反复调用文案、参考链接、图片和素材说明
- 研究、运营与知识工作者：在浏览器、文档、聊天工具之间高频复用内容
- 注重隐私的用户：希望保留效率，但不希望敏感内容被无差别长期暴露

## 一次找回是怎么完成的

1. 复制内容，ClipFlow 自动记录最近历史。
2. 通过 `Option + V` 呼出快捷面板，面板会出现在当前操作附近。
3. 根据内容类型和预览快速识别目标条目。
4. 选择后立即回贴，继续当前工作，不打断思路。

## 你会得到什么

- **快捷粘贴**：在鼠标附近快速呼出最近历史，减少窗口切换和来回翻找
- **历史内容库**：集中查看、筛选和管理已复制内容，适合高频复用场景
- **内容识别**：自动区分普通文本、链接、代码、图片和敏感内容，降低识别成本
- **图片支持**：记录图片、显示缩略图，并保留尺寸等基础信息
- **隐私保护**：支持排除应用、暂停监听、敏感内容遮罩，以及本地优先的保存边界
- **状态栏入口**：无需常驻大窗口，也能快速查看状态、打开主界面和控制监听
- **原生集成**：针对 macOS 交互习惯设计，保持轻量、直接、低打扰的使用感受

## 快速开始

1. 系统要求：`macOS 14+`
2. 前往 [GitHub Releases](https://github.com/Forest227/ClipFlow/releases) 下载最新版本
3. 将 `ClipFlow.app` 拖入 `Applications`
4. 首次使用时按提示授予“辅助功能”权限
5. 开始复制内容，并用 `Option + V` 呼出快捷面板

未授予“辅助功能”权限时，ClipFlow 仍可记录历史，但无法自动完成回贴。

## 从源码运行

如果你希望本地运行或自行构建，可以使用：

```bash
swift build
swift run ClipFlowApp
```
