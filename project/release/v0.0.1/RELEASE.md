# ClipFlow v0.0.1 发布说明

> 发布日期：2026-04-03
> 版本号：0.0.1
> 构建号：1

## 版本简介

ClipFlow 的首个公开版本，围绕 macOS 原生工作流提供更轻量、更高效的剪切板体验。核心目标是让用户在不打断当前上下文的前提下，快速找回并重新粘贴最近复制过的内容。

## 主要功能

- 支持按 `Option + V` 在鼠标附近呼出快捷面板
- 支持状态栏菜单快速查看最近复制内容
- 支持主窗口历史库浏览、筛选与管理
- 支持文本、链接、代码、图片等内容类型识别
- 支持图片缩略图预览与尺寸展示
- 支持链接识别与一键访问
- 支持敏感内容遮罩、排除应用、暂停监听、自动过期等隐私保护能力
- 支持开机启动、启动后驻留状态栏
- 提供中文界面
- 提供 iCloud 同步开关入口

## 体验改进

- 快捷面板尽量贴近鼠标位置显示，减少工作流打断
- 主窗口、状态栏菜单和快捷面板保持紧凑高密度布局
- 重点优化内容识别、视觉层级和回贴效率
- 尽量采用 macOS 原生窗口、毛玻璃材质和系统级交互体验

## 使用提醒

- 首次使用自动粘贴能力时，macOS 可能会请求“辅助功能”权限
- 如果没有授予该权限，应用仍可记录历史，但无法自动回填到目标输入框
- iCloud 同步需要正确签名和对应 capability，当前本地 ad-hoc 构建可能不可用
- 当前版本面向 macOS 14 及以上系统
