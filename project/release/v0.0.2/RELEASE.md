# ClipFlow v0.0.2 发布说明

> 发布日期：2026-04-05
> 版本号：0.0.2
> 构建号：1
> 对应提交：`292d9f3`

## 版本简介

这一版基于当前 `project` 分支重新构建，重点延续快捷呼出与外观体验的打磨，并进一步修正了设置页中高频操作区域的可点性和可读性。

## 主要更新

- 优化设置页“外观”三态切换按钮
- 扩大“跟随系统 / 浅色 / 深色”三个选项的点击范围
- 提升外观按钮的文字与图标对比度，让选中态更清楚
- 统一排除应用编辑框与滚动区域的底色，减少内外层色差
- 保留自定义全局快捷键能力，主窗口、状态栏菜单和快捷面板会同步显示当前组合键
- 保留并延续历史记录、快速粘贴、敏感内容保护、图片支持与状态栏控制等核心能力

## 体验改进

- 外观模式切换更容易点中，降低误点和漏点
- 选中态与未选中态的层级更明确，扫一眼就能看清当前模式
- 设置页整体视觉更统一，输入区与滚动容器的边界更自然
- 这一版继续基于当前分支快照重建，便于直接作为测试分发包使用

## 使用提醒

- 首次使用自动粘贴能力时，macOS 可能仍会请求“辅助功能”权限
- 如果没有授予该权限，ClipFlow 仍可记录历史，但无法自动向目标应用发送粘贴操作
- 当前发布包为本地 ad-hoc 构建版本，适合测试、预览和手动分发
- 当前版本面向 macOS 14 及以上系统
