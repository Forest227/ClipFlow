# ClipFlow v0.0.1

ClipFlow 的首个公开版本，带来一套围绕 macOS 原生工作流打造的剪切板体验：在指针附近快速呼出、快速浏览历史、快速回贴内容，同时尽量把隐私保护放进默认交互里。

## 本次发布

- 新增快捷呼出面板，支持按 `Option + V` 在鼠标附近打开
- 新增状态栏菜单，可查看最近内容并执行常用操作
- 新增主窗口历史库，支持按内容类型浏览和管理复制记录
- 新增图片复制记录，支持缩略图预览与分辨率展示
- 新增链接识别与“访问链接”按钮
- 新增敏感内容保护策略，包括遮罩、排除应用、暂停监听与自动过期
- 新增开机自动启动与启动时直接驻留状态栏选项
- 新增可选 iCloud 同步开关，用于同步普通历史内容
- 完成主界面、状态栏菜单、快捷面板、设置页的中文化

## 体验优化

- 优化快捷面板定位逻辑，尽量在鼠标附近完整显示
- 优化主页面与状态栏菜单布局，让整体更紧凑、清晰、整洁
- 优化图片条目展示方式，避免缩略图挤占图标区域
- 优化详情查看交互，支持在不同入口查看完整复制信息
- 修复多项窗口、浮层、按钮样式与交互细节问题

## 使用提醒

- 首次使用一键粘贴时，macOS 可能会请求辅助功能权限
- 若未授予辅助功能权限，ClipFlow 无法自动把内容粘贴回目标输入框
- iCloud 同步需要正确签名并启用 iCloud capability，当前本地 ad-hoc 构建可能显示为不可用

## 安装文件

- `ClipFlow-v0.0.1.dmg`
- `ClipFlow-v0.0.1.dmg.sha256`

## 已知说明

- 当前版本主要面向 macOS 14+
- 这仍是一个持续演进中的初版，后续会继续完善同步、签名发布与更多内容类型支持
