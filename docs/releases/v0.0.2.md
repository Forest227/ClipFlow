# ClipFlow v0.0.2 发布说明

> 发布日期：2026-04-03

## 主要更新

### UI 架构重构

将 2753 行的 `ContentView.swift` 拆分为 7 个功能模块文件，建立设计 Token 系统，统一按钮样式和交互组件。代码更易维护，不改变任何功能和视觉效果。

**新增文件：**
- `DesignTokens.swift` — 集中管理间距、圆角、排版、调色板
- `ButtonStyles.swift` — 2 个可配置按钮样式替代原来 7 个近似样式
- `InteractiveHostingView.swift` — 1 个通用交互卡片替代 3 个重复的 NSViewRepresentable
- `SharedComponents.swift` — 所有通用 UI 组件（毛玻璃面板、徽章、缩略图等）
- `InspectorOverlay.swift` — 详情浮层与权限检测浮层
- `MenuBarView.swift` — 状态栏弹出菜单及子组件
- `SettingsView.swift` — 设置页面及子组件

**消除重复：**
- `ClipboardKind` 新增 `.tint` 和 `.iconName` 计算属性，消除 5 处重复的颜色映射和 2 处重复的图标映射

### 外观模式选择

设置页新增「外观」面板，支持三种模式：
- **浅色** — 强制浅色主题
- **深色** — 强制深色主题
- **跟随系统** — 自动跟随 macOS 系统设置（默认）

选择会持久保存，所有窗口（主窗口、设置、状态栏菜单、快捷呼出面板）均会响应。

### 深色/浅色外观全面适配

修复了状态栏面板和快捷呼出面板（Option+V）不响应外观设置的问题。为所有面板组件设计了完整的明暗双模式配色：

- 状态栏弹出菜单：Header 渐变、StatPill、条目行、按钮边框均适配深色
- 快捷呼出面板：面板边框、行填充、文本框、关闭按钮均适配深色
- HUD 详情浮层：卡片背景、边框、阴影均适配深色
- 菜单按钮样式：边框色自适应明暗模式

### 状态栏 StatPill 排版优化

将三个状态指标（历史/隐私/呼出）从横向图标+文字布局改为纵向居中布局（图标在上、数值+标题在下），在 320px 宽度内均匀分布，不再挤压溢出。

### 技术设计文档

新增 `docs/clipflow-technical-design.md`，覆盖架构总览、数据模型、核心服务、视图架构、设计系统、持久化策略、安全隐私、构建发布等完整技术文档。
